# ProfitPilot AI

## AI-Powered Business Intelligence Platform

ProfitPilot AI is a modern and responsive SaaS landing page designed to help businesses understand their financial performance and make smarter decisions using AI-powered insights.

The platform focuses on helping users analyze key business metrics such as revenue, expenses, profitability, and potential business opportunities.

---

## ✨ Features

- Responsive navigation bar
- Modern Hero section with call-to-action buttons
- Business analytics feature cards
- How It Works section
- Pricing plans
- Contact / Demo Request form
- Basic form validation
- Success message after form submission
- Fully responsive design for desktop and mobile devices
- Smooth navigation between website sections

## ⚙️ How to Run the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/bhumikachauhan20052005-crypto/profitpilot-ai.git
```

### 2. Navigate to the project folder

```bash
cd profitpilot-ai
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will then be available on the local development URL shown in the terminal.
